# Australian Domestic One-Day Cricket Data Analysis

## Project Overview
This project explores Australian Domestic One-Day Cricket data using Python and Pandas.

## Analysis Includes
- Total runs and balls faced
- Batting average and strike rate
- Runs per innings
- Fours and sixes analysis
- Dot-ball analysis
- Top batsmen comparison

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Project Type
Hands-on Data Analysis Learning Project.
